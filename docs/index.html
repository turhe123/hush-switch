Features

Built for the unmuted moment.

A small menu bar utility that does one job and keeps its state honest.

Global hotkey, any app

Record any key combination in Settings. HushSwitch warns you if macOS or another app already uses it.

Toggle, push-to-talk, push-to-mute

Stay muted until you hold the key, stay live until you hold it, or simply toggle. Key auto-repeat is ignored.

Always shows the real state

The menu bar icon shows a mic when live and a red slashed mic when muted. It stays correct even if another app changes the mute or volume.

Floating ON AIR indicator

An optional click-through pill appears on every Space only while your mic is live. Place it in any screen corner.

Pick the device to control

Follow the system default input or choose a specific microphone. If a device has no mute control, HushSwitch sets its input volume to zero and restores it on unmute.

No accounts, no recording

It never records or reads audio and has no servers or analytics. It only changes device properties through CoreAudio.

Install

Up and running in a minute.

HushSwitch is open source and not notarized with a paid Apple Developer ID, so macOS needs one extra step the first time.

  1. Download HushSwitch-macOS.zip and unzip it.
  2. Move HushSwitch.app to your Applications folder.
  3. Clear the quarantine flag once, then right-click the app and choose Open:
    xattr -cr /Applications/HushSwitch.app
  4. No special permissions are required. The optional Launch at login toggle adds a login item you can review in System Settings General Login Items.

FAQ

Questions, answered.

Is HushSwitch really free and open source?

Yes. HushSwitch is free and released under the MIT license, with the full source on GitHub. It has no accounts, no servers and no analytics.

What permissions does it need?

None. The hotkey uses Carbon RegisterEventHotKey, so Accessibility is not needed, and the app never records audio, so Microphone access is not needed either. The only system interaction is the optional Launch at login item.

Where is my data stored?

Only on your Mac. Your settings, such as the hotkey, mode and indicator position, are saved in the app's local preferences. Nothing is sent anywhere.

Why isn't the app notarized?

Notarization requires a paid Apple Developer account, and HushSwitch is a free project. Right-click the app and choose Open once to get past Gatekeeper, or build it yourself from source with Xcode and XcodeGen.

Was this written by AI?

Yes. HushSwitch was generated by Claude Code from a written spec as a clean-room reimplementation, with no code or assets from any commercial app. The full source is on GitHub under MIT, so you can read every line before you run it. It has had less human review than a hand-written app, so bug reports are welcome.
